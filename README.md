# Bumper Sticker Maker & Generator 🚗
**Create custom, funny bumper stickers instantly and download high-resolution files for printing.**

## 🚀 [Launch the Live Tool](https://bottleyourbrand.github.io/bumper-sticker-maker/)

### About this Tool
This open-source tool allows you to generate random funny bumper sticker sayings or write your own. It includes a live preview, font selection, and color customization.

**Features:**
* **Saying Generator:** Click to cycle through hundreds of funny slogans.
* **Custom Text:** Click the sticker to type your own message.
* **High-Res Download:** Exports a 300 DPI PNG file perfect for professional printing.
